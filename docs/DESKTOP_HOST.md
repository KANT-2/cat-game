# 데스크톱 오버레이 호스트

데스크톱 호스트는 기존 PWA/PixiJS 프런트엔드를 다시 구현하지 않고 Tauri 2 WebView로 감싼다.
운영체제 창 기능은 `src-tauri/`에만 두며 `src/game/`, `src/domain/`, `src/core/`에서는 Tauri API를
사용하지 않는다.

## 현재 프로토타입

`widget` 창 하나가 기존 Vite 화면을 표시하며 다른 일반 창보다 위에 유지된다. 첫 단계에서는 운영체제
기본 창틀과 작업표시줄 항목을 유지하므로 창을 직접 이동하거나 닫을 수 있다. 개발과 빌드는 다음
명령을 사용한다.

```bash
npm run desktop:check
npm run desktop:dev
npm run desktop:build
```

`desktop:dev`는 5173 포트에서 Vite를 함께 시작한다. 이미 별도 개발 서버가 실행 중이면 먼저 종료해야
한다. `desktop:config:check`는 공유 프런트엔드 경로와 항상 위 설정이 유지되는지 검사한다.

투명·무테 창은 아직 적용하지 않는다. 현재 Canvas가 숲 배경을 화면 전체에 그리고 트레이 메뉴도 없기
때문에 먼저 일반 창으로 항상 위 동작을 확인한다. 다음 단계에서 데스크톱 표시 모드를 별도로 전달해
배경과 큰 HUD를 숨기고, 고양이와 필요한 상호작용 영역만 렌더링한다.

## 의도적으로 남긴 범위

- 투명·무테 위젯과 창 잠금·숨김을 제공하는 트레이 메뉴
- 투명 픽셀에서 아래 바탕화면으로 입력을 전달하는 영역별 클릭 통과
- 위치·크기·모니터 저장과 복원
- 전체 화면 앱·화면 잠금 감지 및 렌더링 중지
- Windows, X11, Wayland별 바탕화면 레이어 결합

항상 위 설정은 Windows와 Linux 창 관리자에서 지원되지만 실제 우선순위와 투명 창 합성은 운영체제와
Wayland 컴포지터 정책의 영향을 받는다. OS별 바탕화면 결합을 게임 화면 코드로 우회하지 않고 후속
플랫폼 어댑터로 추가한다.
