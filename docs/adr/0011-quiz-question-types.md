# 퀴즈는 자동 채점 가능한 네 가지 유형으로 시작한다

MVP의 퀴즈는 개념 이해 선택형, 짧은 코드의 실행 결과 예측, 오류 원인 또는 올바른 코드 선택, O/X 유형으로 제공한다. 자유 서술형 답변은 정답 판정의 일관성과 생성 검증의 어려움 때문에 후속 범위로 둔다.

## Considered Options

- 자유 서술형을 포함한 다양한 답변 방식
- 자동 채점 가능한 선택형·예측형·오류 판별형·O/X

## Consequences

즉각적이고 일관된 채점이 가능하지만, 개념을 자신의 말로 설명하는 능력은 별도의 오프라인 학습 세션이나 후속 기능에서 다뤄야 한다.
