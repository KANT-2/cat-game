# AI 생성 콘텐츠에는 검토 관문을 둔다

Gemini가 생성한 문제는 모두 구조·문법·실행·테스트 자동 검증을 거친다. 새로운 문제 유형이나 새로운 개념은 교육 담당자가 검토한 뒤 문제 은행에 등록하고, 기존에 승인된 유형의 단순 변형은 자동 검증 통과 시 등록한다. 오류 신고가 누적된 문제는 비활성화한다.

## Considered Options

- 모든 AI 생성 문제를 즉시 자동 등록
- 모든 문제를 사람만 검토
- 자동 검증을 기본으로 하되 위험도가 높은 신규 영역에 사람 검토를 적용

## Consequences

콘텐츠 확장 속도와 교육적 품질을 함께 확보할 수 있지만, 문제 유형·개념의 승인 상태와 오류 신고에 따른 비활성화 절차를 관리해야 한다.
