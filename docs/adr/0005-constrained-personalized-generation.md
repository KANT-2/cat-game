# 검증 제약 안에서 개인화 연습 과제를 생성한다

Gemini는 학습자의 수준에 맞춰 개인화 연습 과제를 생성하지만, 과제 유형·학습 개념·입출력 형식·채점 가능성은 사전에 정의된 검증 규칙이 결정한다. 생성 모델의 자유로운 답변이나 설명만을 정답 판정의 근거로 사용하지 않는다.

## Considered Options

- 자유 형식으로 Gemini가 문제와 정답·채점 기준을 모두 생성
- 검증 가능한 과제 틀 안에서 Gemini가 문제의 변형과 표현을 개인화

## Consequences

생성 결과를 검증·거부·재생성하는 흐름이 필요하며, 개인화의 폭은 과제 템플릿과 검증 규칙이 허용하는 범위로 제한된다. 대신 실행 가능한 과제의 안정성과 채점 신뢰성을 확보할 수 있다.
