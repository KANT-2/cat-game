# 고양이마다 고정 페르소나를 부여한다

수집한 고양이는 각각 고유한 성격·말투·선호 주제를 가진다. Gemini는 고양이 페르소나가 정한 범위 안에서 자유롭게 응답하지만, 안전 정책과 학습 콘텐츠의 신뢰 경계는 모든 고양이에게 동일하게 적용한다.

## Considered Options

- 모든 고양이가 동일한 말투와 성격으로 응답
- 고양이마다 고정된 페르소나를 가지고 응답

## Consequences

고양이 수집에 대화적 차별성을 부여할 수 있지만, 각 페르소나의 경계와 일관성을 관리해야 하며 페르소나가 안전 정책을 우회하지 못하게 해야 한다.
