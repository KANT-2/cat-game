# 순위는 선택적 소규모 그룹에서만 제공한다

게임은 학습자가 참여를 선택한 친구·학급·스터디 등의 제한된 그룹 안에서 순위를 제공한다. 전체 학습자 대상 순위는 MVP 범위에서 제외하며, 순위는 개인 숙련 티어와 별개의 경쟁 기능으로 취급한다.

## Considered Options

- 전체 학습자 대상 순위
- 순위 기능 자체를 제공하지 않음
- 참여자가 선택한 소규모 그룹의 순위

## Consequences

학습자가 아는 범위 안에서 경쟁할 수 있고 비교 부담을 줄일 수 있다. 그룹 가입·탈퇴, 닉네임 노출, 부정행위와 순위 산정 기준을 별도로 설계해야 한다.
