# Python 과제는 함수 작성형으로 시작한다

MVP의 Python 과제는 학습자가 정해진 함수의 로직을 작성하고, 채점기가 여러 입력값에 대한 반환값과 동작을 테스트하는 방식으로 제공한다. 표준 입력·출력을 직접 처리하는 전체 스크립트 과제는 후속 범위로 둔다.

## Considered Options

- 표준 입력·출력을 처리하는 전체 스크립트 작성
- 정해진 함수의 로직을 작성하는 함수 작성형 과제

## Consequences

초보자가 입력 파싱보다 핵심 개념과 문제 해결에 집중할 수 있고 모바일 화면에서도 과제를 단순하게 제공할 수 있다. 대신 초기 과제는 함수 호출 환경과 반환값 중심으로 설계해야 한다.

함수 이름과 매개변수는 고정하고 학습자는 함수 본문만 편집한다. 예시 입출력은 공개하며, 기본 코드와 테스트 코드는 학습자가 수정할 수 없도록 한다.
