# 하우징은 격자 기반으로 배치한다

MVP의 하우징은 격자 칸에 가구와 소품을 배치하는 방식으로 제공한다. 학습자는 배치한 요소를 이동·회전·삭제할 수 있고, 벽지와 바닥을 선택해 적용할 수 있다. 자유 크기 조절과 복잡한 물리 배치는 후속 범위로 둔다.

## Considered Options

- 자유 좌표와 크기 조절을 지원하는 정밀 배치
- 격자 기반의 단순 배치

## Consequences

일반 브라우저와 설치형 PWA에서 일관된 조작과 저장이 쉽고, 후속 플랫폼 어댑터에서도 같은 논리 좌표를 재사용할 수 있다. 초기 하우징의 표현력은 격자와 준비된 장식 요소의 품질에 의존한다.
