# 하우스 방문은 읽기와 긍정적 돌봄만 허용한다

방문자는 다른 학습자의 하우스를 구경하고 고양이를 쓰다듬거나 놀아주며 정해진 선물을 줄 수 있다. 방문자는 소유자의 가구를 이동·삭제·교체하거나 고양이와 장식품을 가져갈 수 없으며, 소유자의 수집·진행 상태를 변경하지 않는다.

## Considered Options

- 방문자에게 하우스 편집이나 자원 변경까지 허용
- 하우스를 읽기 전용으로 공개하고 제한된 긍정적 돌봄만 허용

## Consequences

사회적 상호작용을 제공하면서 소유권과 진행 상태를 보호할 수 있다. 방문 돌봄의 보상과 방문 권한·공개 범위는 별도로 설계해야 한다.
