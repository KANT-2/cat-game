# 고양이 대화는 정서적 동반자 기능으로 제한한다

학습자는 고양이에게 자유롭게 입력할 수 있고, 고양이는 Gemini를 통해 동반자다운 응답을 제공한다. 고양이 대화는 문제 은행의 연습 과제, 정답·채점, 개념별 숙련도 판정의 권위 있는 출처가 아니며, 코딩 질문은 검증된 학습 콘텐츠로 안내하는 범위로 제한한다.

## Considered Options

- 고양이가 자유 대화와 코딩 튜터 역할을 함께 수행
- 자유 대화는 허용하되 고양이를 정서적 동반자로 제한

## Consequences

고양이의 역할과 학습 콘텐츠의 신뢰 경계를 명확히 유지할 수 있다. 자유 입력을 처리하므로 안전한 응답 정책, 유해 콘텐츠 대응, 개인정보 보호를 별도로 설계해야 한다.
