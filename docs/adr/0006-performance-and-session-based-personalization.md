# 수행 데이터와 오프라인 학습 이력으로 개인화한다

개인화 연습 과제는 학습자의 게임 내 수행 데이터와 오프라인 학습 세션 이력을 함께 사용해 생성한다. 수준은 하나의 종합 레벨이 아니라 개념별 숙련도 프로필로 표현하며, 오프라인 학습 이력은 학습 범위와 초기 맥락을 제공하고 게임 내 수행은 실제 적용 능력을 보완한다.

## Considered Options

- 자기 평가 또는 단일 종합 점수로 개인화
- 게임 내 수행 데이터만 사용
- 게임 내 수행 데이터와 오프라인 학습 이력을 결합

## Consequences

오프라인 세션 정보와 게임 수행 결과를 연결하는 학습 이력의 기준이 필요하다. 개인화는 개념별로 정교해지지만, 데이터가 부족한 신규 학습자에 대한 초기 처리도 설계해야 한다.
