# 오답은 즉시 피드백과 재시도로 연결한다

퀴즈와 코드 과제는 제출 직후 결과를 알려주며, 오답에는 관련 개념의 짧은 설명과 단계적인 힌트를 제공한다. 재시도 횟수는 제한하지 않고 오답에 점수·재화 차감도 두지 않으며, 힌트 사용은 기본 보상을 유지한 채 추가 보상에만 영향을 준다.

## Considered Options

- 오답을 누적해 벌점을 주고 재시도를 제한
- 즉시 피드백과 무제한 재시도로 오답을 학습 과정에 포함

## Consequences

실패에 대한 심리적 부담을 낮추고 반복 학습을 촉진하지만, 자동 생성된 설명과 힌트도 사실성·난이도 검증 대상이 된다.
