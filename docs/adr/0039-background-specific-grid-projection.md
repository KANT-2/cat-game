# 배경마다 바닥 격자의 화면 투영을 따로 둔다

상점 배경은 모두 `1600 × 900` 벨트뷰지만 숲, 골목, 실내, 책상, 바다 이미지의 바닥 시작선과
앞쪽 경계가 같지 않다. 하나의 사다리꼴을 모든 이미지에 사용하면 고양이와 가구가 벽, 물, 책상 모서리
위에 놓여 보인다.

## Considered Options

- 모든 배경 이미지를 하나의 공통 카메라 구도로 다시 제작
- 배경마다 저장 격자와 충돌 규칙까지 분리
- `10 × 8` 논리 격자는 공유하고 화면 투영 사다리꼴만 배경별로 등록

## Consequences

`activeWallpaper`에 따라 `BackgroundGrid`가 `centerX`, `farY`, `nearY`, `farWidth`, `nearWidth`를
선택한다. 배경을 바꾸면 바닥 입력 셀, 고양이, 가구, 배치 미리보기를 같은 프로필로 다시 투영한다.
셀 수와 가구의 논리 좌표, 점유 크기, 충돌 판정은 유지하므로 저장 및 API 마이그레이션은 필요하지 않다.

이 결정은 ADR 0037의 “모든 장소가 같은 화면 격자를 공유한다”는 부분을 대체한다. 새 배경은 이미지
카탈로그 등록과 함께 바닥의 안전 영역을 측정해 프로필을 추가해야 한다. 배경 상품과 프로필의 누락은
단위 테스트에서 실패하도록 유지한다.
