# 코드 과제의 전체 시작 코드를 편집할 수 있게 한다

함수 선언을 별도의 읽기 전용 영역으로 고정하면 초보자가 함수 구조를 통째로 읽고 수정하는
경험을 하지 못하고, 붙여넣기·전체 선택·초기화 동작도 본문 일부에만 적용되어 일반적인 코드
편집기와 다르게 느껴진다.

## Considered Options

- 함수 선언을 읽기 전용 행으로 계속 고정
- 고정 선언을 유지하되 복사·붙여넣기 기능만 확장
- 함수 선언과 본문을 포함한 전체 시작 코드를 편집 가능한 초기값으로 제공

## Consequences

`CodeChallengeView` 및 문제 정의는 `starterCode`로 전체 초안을 제공한다. CodeMirror에는 별도의 고정
선언 영역을 두지 않고 초안 전체를 넣으며, 초기화·복원·붙여넣기·제출은 모두 같은 전체 문서에
적용한다. 채점기는 요구한 함수 진입점을 테스하므로, 학습자가 선언을 잘못 바꾸면 자연스럽게 오답으로
판정된다. 채점 테스트는 계속 서버 또는 로컬 판정 계층에 두어 편집할 수 없다.

이 결정은 ADR 0010의 “함수 이름과 매개변수를 고정한다”는 편집 UI 제약을 대체한다. 함수 단위로
채점한다는 과제 형식 자체는 유지한다.
