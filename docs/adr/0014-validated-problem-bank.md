# 검증된 문제 은행에서 개인화 과제를 선택한다

Gemini는 콘텐츠 준비 단계에서 문제와 변형 후보를 생성하고, 자동 검증을 통과한 항목만 문제 은행에 등록한다. 게임 실행 중에는 학습자의 개념별 숙련도에 맞는 항목을 문제 은행에서 선택하며, 필요할 때 검증된 템플릿의 안전한 값만 변형한다.

## Considered Options

- 학습자가 과제를 요청할 때마다 자유 형식으로 생성
- 검증된 문제 은행에서 선택하고 준비 단계에서 AI로 확장

## Consequences

제공되는 문제의 품질과 채점 가능성을 사전에 확인할 수 있고 응답 지연과 생성 비용을 줄일 수 있다. 대신 문제 은행의 범위와 신선도를 유지하기 위한 콘텐츠 관리 절차가 필요하다.
