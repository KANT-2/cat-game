# 하우징은 꾸미기 전용이다

하우징은 가구·벽지·바닥·소품으로 개인 공간을 꾸미는 수집 보상이며, 학습 점수·문제 난이도·고양이 획득 확률 같은 게임 성능에는 영향을 주지 않는다. 학습 기능은 특정 하우징 요소의 보유 여부와 무관하게 이용할 수 있다.

## Considered Options

- 하우징 요소가 학습이나 고양이 성장에 능력치 보너스를 제공
- 하우징을 시각적 표현과 수집 보상으로만 제공

## Consequences

꾸미기의 자유와 보상 가치는 유지하면서 학습·경쟁의 공정성을 보호할 수 있다. 하우징의 재미는 배치·상호작용·고양이 반응 같은 표현 요소로 만들어야 한다.

MVP의 공간 꾸미기는 간단한 격자에 가구와 소품을 배치하고 이동·회전·삭제하는 방식으로 제공한다. 벽지와 바닥은 선택해 적용하며, 자유 크기 조절과 복잡한 물리 배치는 포함하지 않는다.
