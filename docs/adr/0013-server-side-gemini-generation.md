# Gemini는 서버에서 호출한다

개인화 연습 과제 생성을 위한 Gemini 호출은 서버에서만 수행한다. 클라이언트는 학습자 수준과 과제 요청을 서버에 전달하고, 서버는 Gemini 결과를 검증한 뒤에만 반환하며 API 키와 생성 정책을 클라이언트에 노출하지 않는다.

## Considered Options

- 브라우저 또는 Tauri 앱에서 Gemini를 직접 호출
- 서버가 Gemini를 호출하고 검증된 결과만 클라이언트에 제공

## Consequences

API 키와 생성 규칙을 보호할 수 있고 모든 플랫폼에서 동일한 검증을 적용할 수 있다. 대신 서버에 생성 비용·지연·장애 대응을 위한 운영 정책이 필요하다.
