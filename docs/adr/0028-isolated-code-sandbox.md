# 학습자 코드는 일회성 격리 샌드박스에서 실행한다

학습자가 제출한 Python 코드는 제출마다 별도의 일회성 샌드박스에서 실행한다. 샌드박스는 네트워크·파일 시스템·프로세스 생성을 차단하고 CPU 시간·메모리·실행 시간·출력 크기를 제한하며, 실행 완료 후 폐기한다.

## Considered Options

- 서버 프로세스에서 학습자 코드를 직접 실행
- 제한된 권한의 장기 실행 워커에서 실행
- 제출별 일회성 격리 실행 환경에서 실행

## Consequences

악성 또는 무한 루프 코드가 다른 학습자와 서버에 미치는 영향을 줄일 수 있다. 샌드박스 생성·폐기 비용과 실행 대기 시간을 관리하고, 제한 초과를 학습자에게 이해하기 쉽게 설명해야 한다.
