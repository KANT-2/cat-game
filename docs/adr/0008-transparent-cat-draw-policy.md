# 고양이 뽑기는 투명하고 회복 가능한 확률형 보상으로 운영한다

고양이 뽑기의 희귀도별 확률은 공개하며, 10+1회 뽑기에 숨겨진 확률 보정은 두지 않는다. 일정 횟수 이상 뽑으면 희귀도 보장을 제공하고, 중복 고양이는 교환 가능한 보상으로 전환하며, 기간 한정 뽑기로 학습자를 압박하지 않는다.

## Considered Options

- 확률과 보장 규칙을 공개하지 않는 일반적인 확률형 보상
- 공개 확률·보장·중복 교환을 포함하는 투명한 확률형 보상

## Consequences

학습자는 보상의 기대값과 실패 시 회복 경로를 이해할 수 있다. 대신 희귀도, 보장까지의 기준, 중복 교환 가치의 균형을 설계하고 학습자에게 명확히 표시해야 한다.
