# 문제 추천과 학습자 선택을 함께 제공한다

게임은 학습자의 개념별 숙련도와 학습 이력에 기반한 문제 추천을 제공하지만, 학습자가 퀴즈·함수 작성형·개념·난이도를 직접 선택하는 것도 허용한다. 추천을 따르지 않아도 불이익은 없으며 선택한 결과는 이후 추천에 반영한다.

## Considered Options

- 시스템이 정한 문제만 순서대로 제공
- 학습자가 모든 문제를 직접 탐색하고 선택
- 개인화 추천을 기본으로 하되 학습자 선택을 함께 제공

## Consequences

개인화의 편의성과 학습자의 자율성을 함께 유지할 수 있다. 선택 범위가 너무 넓어지지 않도록 개념·난이도 탐색 화면을 단순하게 구성해야 한다.
