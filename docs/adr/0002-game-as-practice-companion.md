# 게임은 오프라인 학습 세션의 연습 보조 도구다

게임은 오프라인 학습 세션을 대체하거나 그 순서를 재현하지 않고, 해당 세션과 별도로 준비된 내용을 학습자가 반복 연습하도록 돕는다. 따라서 MVP의 핵심 단위는 고정된 수업 흐름이 아니라 독립적으로 선택하고 풀 수 있는 연습 과제다.

## Considered Options

- 게임 안에서 개념 설명부터 순차적으로 가르치는 독립형 학습 과정
- 오프라인 학습 세션과 연계되는 연습 보조 도구

## Consequences

게임은 오프라인 세션의 전제 지식을 존중해야 하며, 콘텐츠를 과제 단위로 관리하고 과제 간 강제 순서를 최소화해야 한다.
