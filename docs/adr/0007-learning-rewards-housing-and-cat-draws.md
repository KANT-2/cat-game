# 학습 재화는 하우징과 고양이 뽑기에 사용한다

연습 과제를 풀어 얻은 학습 재화를 하우징 요소 구매와 고양이 뽑기에 사용한다. 고양이 뽑기는 단일 뽑기와 10회 비용으로 11마리를 획득하는 10+1회 뽑기를 제공한다. 학습 재화의 현금 구매·거래·선물은 제공하지 않으며, 세부 확률과 중복 처리는 별도 결정으로 남긴다.

## Considered Options

- 학습 결과를 점수·등급 중심으로만 보상
- 학습 재화를 수집형 하우징과 고양이 획득에 연결

## Consequences

보상이 학습 행동과 직접 연결되어 반복 동기를 제공하지만, 뽑기 확률과 중복 보상은 공정성·투명성·과도한 반복 유도 여부를 별도로 설계해야 한다. 현금 결제가 없으므로 결제 유도 설계는 범위에서 제외한다.

연습 과제를 처음 완료하면 기본 학습 재화를 지급하고, 정답 또는 테스트 통과에는 추가 보상을 지급한다. 힌트 사용은 기본 보상을 없애지 않고 추가 보상에만 영향을 주며, 동일 과제의 무제한 반복 보상은 허용하지 않는다. 오답에는 재화 차감이나 벌칙을 두지 않는다.
