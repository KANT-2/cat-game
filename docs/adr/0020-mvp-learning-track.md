# MVP는 Python 기초 학습 트랙에 집중한다

첫 번째 학습 트랙은 값·변수·기본 자료형, 연산자·조건문, 반복문, 함수, 문자열·리스트, 간단한 디버깅·알고리즘 사고를 다룬다. 자료구조 심화, 객체지향, 재귀, 복잡도 분석, 컴퓨터 구조 등은 후속 범위로 둔다.

## Considered Options

- 프로그래밍과 컴퓨터과학 전 범위를 초기부터 포함
- Python 기초 개념과 문제 해결의 핵심 범위에 집중

## Consequences

초보자에게 일관된 난이도와 콘텐츠 품질을 제공할 수 있지만, 초기 문제 은행과 개인화는 이 트랙의 개념 태그를 중심으로 설계해야 한다.
