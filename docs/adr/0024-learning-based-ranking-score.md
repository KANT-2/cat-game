# 순위는 학습 점수로 산정한다

선택적 소규모 순위는 순위 전용 학습 점수로 산정한다. 처음 해결한 연습 과제의 정확도와 난이도, 업적 달성을 반영하며, 오답·힌트 사용은 감점하지 않는다. 동일 과제 반복 풀이로 무한히 점수를 얻거나 풀이 속도만으로 우위를 얻을 수 없으며, 학습 재화와 순위 점수는 분리한다.

## Considered Options

- 보유 학습 재화나 풀이 횟수로 순위를 계산
- 속도 중심 점수
- 검증된 학습 성과를 반영하는 별도 순위 점수

## Consequences

순위가 실제 학습 활동과 연결되고 파밍·속도 경쟁을 줄일 수 있다. 과제 난이도와 업적별 점수의 균형, 동일 성취의 공정한 비교를 지속적으로 조정해야 한다.
