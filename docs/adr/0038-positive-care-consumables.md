# 간식은 소모되는 긍정적 돌봄 상호작용으로 제공한다

상점에 연어 큐브, 닭가슴살 스트립, 캣닢 비스킷, 참치 크림 수프를 추가한다. 구매한 간식은 보관함에서
보유 고양이에게 한 번 사용할 수 있고, 사용 직후 수량 한 개가 줄어들며 고양이가 상품별 짧은 반응을 한다.

## Considered Options

- 허기 수치를 두고 정기적으로 간식을 요구
- 간식을 영구 능력치 또는 학습 보너스로 사용
- 수량만 소비하고 긍정적인 시각 반응을 제공

## Consequences

간식은 수집·상호작용을 풍부하게 하지만 방치 패널티, 능력치와 학습 보상에는 영향을 주지 않는다. 수량 차감은
`GameClient` 명령이며 원격 모드에서는 서버가 보유 고양이와 간식을 잠근 뒤 멱등하게 처리한다. UI는 성공
결과의 효과만 애니메이션으로 표현한다. 이 결정은 하우징을 성능과 분리한 ADR 0025의 원칙을 유지한다.
