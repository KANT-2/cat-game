# 온라인 연결을 필수로 한다

게임의 권위 있는 학습 기능은 인터넷 연결이 가능하다는 전제로 설계한다. 퀴즈 콘텐츠, Python 코드 실행·채점, 진행 상태 저장은 온라인 서비스를 사용하며, 완전한 오프라인 학습 실행과 동기화는 MVP 범위에서 제외한다. 다만 PWA는 정적 앱 셸과 메인화면 리소스를 캐시해 네트워크 없이 다시 열 수 있으며, 이 동작은 오프라인 학습 지원을 뜻하지 않는다.

## Considered Options

- 핵심 기능을 오프라인에서도 제공
- 온라인 연결을 필수 전제로 설정

## Consequences

서버 기반 콘텐츠와 실행 환경을 활용할 수 있지만, 연결 끊김과 서비스 장애에 대한 학습자 안내 및 복구 경험은 별도로 설계해야 한다. 캐시된 앱 셸은 접근 경로를 유지하고 온라인 기능은 연결 상태를 명확히 표시한다.
