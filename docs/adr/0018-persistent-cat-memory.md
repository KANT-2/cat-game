# 고양이 기억은 세션 간 유지한다

고양이는 학습자와의 일반적인 대화와 관계 맥락을 다음 접속에서도 기억한다. 이 기억은 고양이 대화의 연속성과 친밀감을 위한 것이며, 학습자의 정답·채점·개념별 숙련도를 결정하는 근거로 사용하지 않는다.

장기 기억은 최근 대화의 제한된 문맥과 구조화된 사실·사건 요약으로 유지하며, 전체 대화 원문을 매번 모델에 전달하지 않는다. 학습자는 저장된 기억을 열람하고 삭제할 수 있다.

## Considered Options

- 대화 세션이 끝나면 기억을 폐기
- 고양이의 관계 기억을 세션 간 유지

## Consequences

고양이를 키우는 감각과 장기적인 관계 형성이 강화되지만, 기억의 표현 방식, 보존 기간, 삭제·열람 정책을 별도로 설계해야 한다.
