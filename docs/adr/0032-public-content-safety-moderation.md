# 공개 콘텐츠에는 필터와 신고 절차를 적용한다

공개 하우스의 이름·고양이 이름·소개 문구에는 기본 금칙어 필터를 적용하고, 고양이 자유 대화에는 별도의 안전 필터를 적용한다. 다른 학습자는 콘텐츠를 신고할 수 있으며, 신고된 콘텐츠는 임시 숨김할 수 있고 반복 위반 계정은 공개·방문 기능을 제한한다. 필터에 걸린 입력은 저장·공개하지 않고 다시 입력하게 한다.

## Considered Options

- 공개 콘텐츠를 별도 관리하지 않음
- 자동 필터·신고·임시 숨김·반복 위반 제한을 결합

## Consequences

공개 하우스와 자유 대화를 유지하면서 부적절한 노출을 줄일 수 있다. 필터 오탐·누락, 신고 검토 절차, 운영자 권한과 이의 제기 방식은 구현 전에 구체화해야 한다.
