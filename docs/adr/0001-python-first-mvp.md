# Python-first MVP

초보 학습자의 인지 부담과 다중 언어 실행·채점 복잡도를 줄이기 위해, MVP에서 직접 작성·실행하는 프로그램 언어는 Python으로 제한한다. 퀴즈는 언어와 무관한 컴퓨터과학 개념을 다룰 수 있으며, 추가 언어 지원은 이후 범위로 둔다.

## Considered Options

- Python과 여러 언어를 동시에 지원
- Python으로 시작하고 이후 언어를 추가

## Consequences

초기 콘텐츠와 실행 환경은 Python에 최적화할 수 있지만, 이후 언어 확장을 고려한 과제·채점 경계는 계획 단계에서 명시해야 한다.
