# Python 과제는 테스트 기반으로 채점한다

Python 코드 과제의 정답 여부는 사전에 정의된 테스트 케이스를 실행해 반환값·출력값·상태 변화 등을 비교하는 방식으로 판정한다. Gemini가 생성한 설명이나 코드의 인상으로 채점하지 않으며, 코드 실행에는 시간·메모리·출력 크기 제한을 둔다.

## Considered Options

- Gemini 또는 다른 언어 모델이 코드의 정답 여부를 판단
- 자유 실행 결과를 사람이 해석
- 격리된 실행 환경에서 결정론적 테스트 케이스로 검증

## Consequences

채점 결과를 재현하고 설명할 수 있지만, 각 과제는 검증 가능한 테스트 케이스를 가져야 하며 실행 환경의 격리·자원 제한이 필요하다.
