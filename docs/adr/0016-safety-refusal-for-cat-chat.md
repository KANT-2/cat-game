# 고양이 대화는 위험한 요청을 회피한다

고양이 대화는 일반적인 자유 입력과 기억·페르소나를 허용한다. 다만 자해·타해 조력, 불법·위험 행동의 실행 방법, 아동 성착취를 포함한 성적 요청, 개인정보 탈취·사기 요청은 고양이의 캐릭터와 무관하게 거절하고 안전한 대안이나 도움 요청 안내로 전환한다. 의료·법률 질문에는 단정적 조언 대신 전문가 상담을 권한다.

## Considered Options

- 고양이의 페르소나를 유지하며 모든 요청에 응답
- 일반 대화는 허용하되 위험 요청에는 안전 전환 적용

## Consequences

자유 대화와 캐릭터성을 유지하면서 예측 가능한 안전 경계를 확보할 수 있다. 안전 판정과 응답 정책은 Gemini의 자유 생성과 분리해 검증·관리해야 한다.
