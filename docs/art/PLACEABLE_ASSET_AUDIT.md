# 배치 자산 전수 조사

2026-09-06에 원격 자산 브랜치의 현재 파일과 전체 Git 이력, 작업 폴더의 `images/` 원본 보드를 함께 대조했다.
같은 그림을 이름만 바꿔 중복 등록하지 않고, 실제 외형이 다른 투명 자산만 런타임 상품으로 연결한다.

## 반영 결과

- `origin/asset/background-items`: 테마별 배치 아이템 54개는 모두 서로 다른 파일이며 전부 `themed-furniture`
  번들에 등록했다.
- `origin/asset/background-props`: 갈대와 이끼바위 2종을 장식 상품으로 등록했다.
- `origin/asset/forest`: 쓰러진 통나무, 두 번째 버섯 벤치, 가지형 캣타워, 이끼 동굴 숨숨집을 추가했다.
  첫 번째 버섯 벤치는 기존 `furniture.sofa`와 동일한 파일이라 중복 등록하지 않았다.
- `images/000_002_잡동사니_소품세트.png`: 골목 소품 10종을 분리했다. 열린 상자는 기존 상품을 재사용했다.
- `images/001_002_방안_소품.png`: 실내 고양이 용품 6종을 분리했다.
- `images/002_001_잡동사니_소품세트.png`: 첫 번째 골목 소품 보드와 같은 내용이라 중복 등록하지 않았다.

최종 상점은 테마 가구 57종과 장식 22종을 제공한다. 런타임 이미지는 투명 WebP이며 파일 경로는
`public/assets/catalog.json`에만 둔다.

## 보류한 원본

- `origin/asset/forest`의 루트 `cat-tower.png`는 다른 그림체와 강한 노랑·빨강 프린지가 있어 제외했다.
- `images/001_002_방안_소품2.png`와 `images/002_002_잡동사니_소품세트.png`는 배경 그라데이션이 픽셀에
  합쳐진 시안판이다. 생성형 배경 분리 결과에도 검은 배경과 갈색 광륜이 남아 품질 검사에서 탈락시켰다.
  개별 원본 레이어 또는 실제 알파 export를 받으면 같은 ID 규칙으로 추가한다.

## 검사 기준

- 검정·흰 배경에서 흰색, 초록색 또는 검은색 프린지가 보이지 않는다.
- 체크무늬나 그림자 배경을 투명도로 오인하지 않는다.
- 바닥 접점 anchor는 물체 하단을 기준으로 `0`부터 `1` 사이에 둔다.
- 상점 상품 ID, 한국어 이름과 가격은 프런트엔드와 서버 카탈로그에서 일치해야 한다.
