# 에셋 제작 공통 규칙

이 문서는 배경과 게임 소품을 만들 때 공통으로 확인하는 쉬운 작업 규칙이다. 필요하면 문장을 직접 고쳐서 팀의 기준으로 사용한다.

## 작업 전 확인

- 어떤 장면에 쓰는 이미지인지 먼저 정한다.
- 같은 장면의 승인된 배경을 기준 이미지로 확인한다.
- 광원 방향, 색상 톤, 원근, 선의 굵기, 디테일 양을 기준 이미지와 맞춘다.
- 한 번에 여러 종류를 만들지 않고 한 종류씩 검토한다.

## 배경 제작 규칙

- 배경은 화면 전체를 채우는 장면 이미지로 만든다.
- 게임에서 필요한 시점과 원근을 먼저 정한다.
- 소품을 나중에 올려도 어색하지 않도록 바닥, 빛, 거리감을 일관되게 만든다.
- 배경에 글자나 UI를 이미지로 굽지 않는다.

## 소품 제작 규칙

- 소품은 다른 이미지와 겹치지 않는 독립 오브젝트로 만든다.
- 나무, 관목, 바위, 풀, 꽃 등은 각각 따로 만든다.
- 소품은 게임 화면에서 작게 보아도 무엇인지 알 수 있는 큰 형태를 먼저 만든다.
- 필요 이상으로 작은 무늬, 잎, 선, 질감을 많이 넣지 않는다.
- 소품 안에 다른 배경 장면, 바닥, 프레임, 글자, 워터마크를 넣지 않는다.

## 투명 PNG 규칙

- 투명 소품은 처음 생성될 때부터 실제 RGBA 투명 PNG여야 한다.
- 소품 바깥 영역은 처음부터 알파값 `0`이어야 한다.
- 체크무늬, 흰색·회색·검은색 배경, 그라데이션, 종이 질감, 바닥, 비네트는 만들지 않는다.
- 생성 후 배경 제거, 누끼, 알파 보정, 색 보정으로 투명도를 만들지 않는다.
- 파일을 받으면 실제 알파 채널과 소품 바깥의 투명도를 확인한다.

## 색상과 광원 규칙

- 기준 배경에 있는 색상 계열 안에서만 작업한다.
- 기준 배경보다 채도가 높거나 대비가 강한 색은 피한다.
- 햇빛, 그림자, 바닥 접점의 방향을 기준 배경과 같게 한다.
- 소품 하나만 튀어 보이면 색상, 밝기, 디테일을 줄인다.

## 승인과 등록 규칙

1. 초안을 만든다.
2. 사용자가 그림체, 색상, 투명도, 형태를 확인한다.
3. 사용자가 명확하게 승인한 경우에만 게임 프로젝트에 저장한다.
4. 승인 후에만 카탈로그에 파일 경로와 anchor를 등록한다.
5. 등록 후 `npm run assets:check`를 실행한다.

## 등록 전 마지막 체크

- 기준 배경과 색상·광원·디테일이 맞는가?
- 독립 소품으로 바로 배치할 수 있는가?
- 이미지 안에 배경이나 체크무늬가 들어가 있지 않은가?
- 실제 투명 PNG인가?
- 사용자 승인을 받았는가?
