# 숲 에셋 스타일 가이드

## 색상 팔레트

숲 배경의 차분한 올리브·황토 계열 안에서만 작업한다. 아래 색상을 섞어 명암을 만들 수 있지만, 전혀 다른 색상 계열을 추가하지 않는다.

| 용도 | 색상 | 사용 방법 |
| --- | --- | --- |
| 깊은 그림자 | `#283419` | 아주 깊은 틈과 작은 어두운 부분에만 사용 |
| 기본 그림자 | `#3F4D26` | 잎과 줄기의 주된 그림자 |
| 중간색 | `#636C2C` | 잎의 기본색과 중간 명암 |
| 밝은 올리브 | `#959331` | 넓은 빛받은 잎 면 |
| 햇빛 강조 | `#D0C149` | 좌측 상단에 닿는 작은 빛 포인트에만 사용 |
| 줄기 황토 | `#886E2C` | 따뜻한 나무줄기 면. 올리브 그림자와 함께 사용 |

청록색, 푸른 그림자, 형광 노랑, 강한 주황, 순수 검정, 과한 색 대비는 사용하지 않는다.

## 광원과 원근

- 빛은 항상 좌측 상단에서 온다.
- 밝은 부분은 작고 차분하게 묶는다. 나무 전체가 노랗게 빛나면 안 된다.
- 밝은 면은 `#959331`을 기본으로 하고, 필요한 곳에만 `#D0C149`를 아주 조금 쓴다.
- 어두운 면은 `#3F4D26`, 더 깊은 곳은 `#283419`로 만든다. 청록색 그림자는 쓰지 않는다.
- 배경은 대비가 낮다. 소품이 배경보다 과하게 입체적이거나 강한 명암을 가지면 안 된다.
- 먼 곳에 놓일 소품은 가까운 소품보다 대비와 디테일을 줄인다.

## 투명 PNG 규칙: 반드시 지킬 것

숲 소품은 처음 생성될 때부터 실제 알파 채널을 가진 RGBA 투명 PNG여야 한다.

- 소품 바깥 전체는 생성 시점부터 알파값 `0`이어야 한다.
- 소품 내부는 불투명해야 하며, 외곽의 부드러운 안티앨리어싱 부분에만 부분 투명도를 쓴다.
- 체크무늬, 흰색·회색·검은색 배경, 그라데이션, 종이 질감, 바닥, 비네트, 프레임, 매트 등 어떤 배경도 생성하지 않는다.
- 생성 후 배경 제거, 누끼, 알파 보정, 매트 제거, 색 보정은 하지 않는다. 이런 작업은 그림체를 바꿀 수 있다.
- 미리보기의 체크무늬만으로 투명하다고 판단하지 않는다. 실제 파일이 RGBA인지와 소품 바깥의 알파값이 `0`인지 확인한다.

## 생성 프롬프트 체크 항목

소품 생성 프롬프트에는 아래 내용을 빠짐없이 넣는다.

- 승인된 숲 배경을 그림체·팔레트 참고용으로만 사용한다.
- 단독으로 배치하는 조립형 게임 소품임을 명시한다.
- 사용할 색상과 금지할 색상 계열을 적는다.
- 큰 형태 중심의 단순화 수준을 적는다.
- 좌측 상단 광원을 적는다.
- 처음부터 소품 바깥 알파값이 `0`인 RGBA PNG만 생성하도록 적는다.
- 체크무늬를 포함한 모든 배경 생성을 금지한다고 적는다.
- 배경 제거 같은 후처리를 하지 않는다고 적는다.
- 사용자 승인 전의 검토용 초안임을 적는다.
